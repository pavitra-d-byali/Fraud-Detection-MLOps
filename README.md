# 🛡️ Real-Time Fraud Detection — MLOps Pipeline

> **Cost-sensitive fraud detection** — model decisions are driven by **business loss minimisation**, not just accuracy.

---

## 📌 Project Overview

This project implements a production-grade fraud detection pipeline on the [Kaggle Credit Card Fraud Dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).

Unlike typical ML demos it explicitly minimises **expected financial loss**:

```
Expected Loss = (False Positives × COST_FP) + (False Negatives × COST_FN)
```

| Cost | Value | Rationale |
|---|---|---|
| `COST_FP` (blocking a legit tx) | 1 | Customer friction |
| `COST_FN` (missing a fraud) | 50 | Financial loss |

## 🏗️ Architecture

```
creditcard.csv
     │
     ▼
src/model/train.py          ← XGBoost + 5-fold CV + threshold tuning
     │ saves
     ▼
models/fraud_detector.pkl   ← model + threshold + cost policy + feature list
     │
     ├──► src/api/app.py        ← FastAPI inference server  (port 8000)
     │         │
     └──► frontend/app.py   ← Streamlit dashboard         (port 8501)
```

| Layer | Technology |
|---|---|
| ML Model | XGBoost (`binary:logistic`) |
| Backend API | FastAPI + Uvicorn |
| Frontend | Streamlit + Plotly |
| Experiment Tracking | MLflow |
| Containerisation | Docker + Docker Compose |
| CI | GitHub Actions |

---

## ✨ Key Features

- **Cost-sensitive threshold tuning** — grid-search over `[0.01, 0.5]` to minimise expected loss on the hold-out set
- **XGBoost with `scale_pos_weight`** — handles 0.17% class imbalance
- **Training–serving consistency** — feature list and threshold are saved in the artifact and re-loaded at serving time
- **Streamlit dashboard** — live health check, Plotly gauge, prediction history, trend chart
- **Docker Compose** — single command starts both backend and frontend
- **GitHub Actions CI** — smoke test on every push

## ⚡ Quick Start (Local)

### 1. Prerequisites

```bash
# Python 3.10+
python --version

# Download dataset from Kaggle and place it at:
# data/creditcard.csv
```

### 2. Install dependencies

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows:
.venv\Scripts\activate

pip install -r requirements.txt
```

### 3. Train the model

```bash
python src/model/train.py --data-path data/creditcard.csv
```

**Training output includes:**
- 5-fold CV ROC-AUC and PR-AUC
- Cost-optimal decision threshold
- Confusion matrix, classification report
- MLflow experiment logged to `mlruns/`
- Saved artifact: `models/fraud_detector.pkl`

### 4. Start the backend API

```bash
uvicorn src.api.app:app --host 0.0.0.0 --port 8000
```

- API docs (Swagger): http://localhost:8000/docs
- Health check: http://localhost:8000/health

### 5. Start the Streamlit frontend

```bash
# In a second terminal
streamlit run frontend/app.py
```

- Dashboard: http://localhost:8501

## 📈 Model Characteristics

| Metric | Note |
|---|---|
| High Recall | Model catches most frauds |
| Lower Precision | Intentional — missing fraud costs 50× more |
| Threshold | Tuned to minimise business loss, not F1 |

> ✔️ This trade-off is **intentional and correct** for a real banking fraud system.
